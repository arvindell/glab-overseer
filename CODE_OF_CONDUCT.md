# Code of Conduct

## Our Pledge

We want `glab-overseer` to be an open, welcoming, and constructive project.
Contributors, maintainers, and community members are expected to participate in
a respectful and professional way.

## Our Standards

Examples of behavior that contribute to a positive environment include:

- Being respectful of differing opinions, experience levels, and approaches
- Giving and receiving feedback constructively
- Focusing on what is best for the project and its users
- Showing empathy toward other community members

Examples of unacceptable behavior include:

- Harassment, intimidation, or discrimination in any form
- Personal attacks, insults, or trolling
- Publishing other people's private information without explicit permission
- Disruptive behavior in issues, pull requests, or discussions

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing this code of
conduct. Maintainers may remove, edit, or reject comments, commits, code,
issues, and other contributions that are not aligned with this code of conduct.

## Scope

This code of conduct applies within all project spaces, including issues, pull
requests, discussions, and other project-managed communication channels.

## Reporting

To report unacceptable behavior, contact the maintainers through GitHub or by
opening a private security report if the issue is sensitive.

## Enforcement

Maintainers may take any action they deem appropriate in response to behavior
that violates this code of conduct, including warning, temporary suspension, or
permanent ban from the project.
